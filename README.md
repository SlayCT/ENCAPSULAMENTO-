# 📚 Atividade 08 — Encapsulamento

Atividade desenvolvida na disciplina de **Técnicas de Programação**, com foco no conceito de **Encapsulamento** na Programação Orientada a Objetos (POO).

## 🎯 Objetivo

Praticar o uso de modificadores de acesso, principalmente `private`, além da implementação de **getters**, **setters** e métodos responsáveis por controlar o acesso e a alteração dos dados dos objetos.

A atividade trabalha três classes:

* 🚗 `Carro`
* 🏦 `ContaBancaria`
* 📦 `Produto`
